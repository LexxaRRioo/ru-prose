# Data engineering

For technical text about data platforms: pipelines, storage, orchestration, streaming, SQL
engines. Load on top of SKILL.md and the medium file whenever the topic is data engineering.

## Terms

- DE terms stay in the form practitioners say them, often English: «compaction» (not
  «компакция»), «lakehouse» (not «озеро»), «трейд-оффы», «at least once», «it depends», «Data
  lake vs Lakehouse». Spell out abbreviations: «Frontend/Backend», not «FE/BE».
- A program that writes or reads a file is not a person. Never «писатель» for an English
  «writer»: name the moment or the setting instead.
  - До: «минимум и максимум на страницу, если писатель их записал» -> После: «минимум и максимум
    на страницу, если их включили при записи файла»

## Work

- Concrete DE work instead of generic verbs: «грузить, мониторить и чинить» -> «описать в коде,
  мониторить и поддерживать».
