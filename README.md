# ru-prose

Скилл для Claude Code с правилами русской прозы. Он помогает писать тексты курсов, слайды, посты и письма так, чтобы они не читались как перевод или сгенерированный текст.

Каждое правило взято из ручных правок автора. Пары «до/после» в файлах - реальные фрагменты: Claude написал первый вариант, автор переписал его.

## Что внутри

| Файл | Для каких текстов |
|---|---|
| `SKILL.md` | общие правила: порядок слов, длина предложений, связки, запрещённые слова, приметы сгенерированного текста, пунктуация |
| `course.md` | уроки, лабы, упражнения, раздатки |
| `slides.md` | слайды, заметки спикера, сценарии видео |
| `posts.md` | посты в личном канале или блоге |
| `author/` | личные привычки автора: обращение на «ты» или «вы» по проектам, дефис вместо длинного тире, «ё», ромбики 🔸 в заголовках постов, нелюбимые слова |

Общие файлы подходят для любого русского текста. Папка `author/` описывает вкус одного человека, и её стоит заменить своей. Можно и удалить: без неё скилл работает на общих правилах.

Правила написаны по-английски, потому что это инструкции для Claude. Примеры остаются на русском.

## Установка

```bash
git clone https://github.com/LexxaRRioo/ru-prose.git ~/.claude/skills/ru-prose
```

Claude Code подхватит скилл при следующем запуске. Его можно вызвать командой `/ru-prose`, а ещё Claude загрузит его сам, когда возьмётся за русский текст.

## Как предложить правило

Буду рад pull request'ам и расширениям: новым правилам, файлам под другие типы текстов, своим папкам вроде `author/`. Приложи пару «до/после»: фрагмент, который написал Claude, и твою правку. Правило без примера из живого текста трудно проверить.
